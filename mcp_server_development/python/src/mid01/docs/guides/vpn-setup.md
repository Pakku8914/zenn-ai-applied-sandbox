# VPN 接続手順

社外から社内システムへ接続するための手順です。所要時間は 15 分程度です。

## VPN クライアントの導入

VPN クライアントは、情報システム部の配布ページから取得します。導入には貸与端末の管理者権限が必要です。

## 接続プロファイルの設定

配布された設定ファイルを読み込み、接続先を選択します。接続先は本社と大阪拠点の 2 つです。認証には社内アカウントの ID とパスワードを使用します。

## 接続の確認

VPN に接続すると、社内システムと共有フォルダーへアクセスできます。

## つながらないときの確認

- 有線・無線どちらの回線でも同じ現象が起きるか
- 設定ファイルの有効期限が切れていないか

解決しない場合は、ヘルプデスクへ連絡してください。
