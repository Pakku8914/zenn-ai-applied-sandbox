# 情報セキュリティ基本方針

## 目的

社内で扱う情報を、機密性・完全性・可用性の 3 つの観点で守るための基本方針を定めます。

## パスワードの管理

パスワードは 12 文字以上とし、他のサービスと使い回さないでください。初期パスワードは、初回ログイン時に必ず変更します。パスワードマネージャーの利用を推奨します。

## 端末とデータの取り扱い

社外ネットワークから社内システムへ接続する場合は、必ず VPN を使用します。顧客データを個人所有の端末へ保存することは禁止です。

## 紛失・盗難時の対応

貸与端末の紛失・盗難に気づいた時点で、直ちに情報システム部へ連絡します。

## 違反時の取り扱い

方針に違反した場合は、就業規則に基づいて対応します。
