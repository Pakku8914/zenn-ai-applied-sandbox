# 入社時セットアップ手順

情報システム部が管理する共通環境のセットアップ手順です。入社初日に、上から順に実施してください。

## 1. 社内アカウントの受け取り

初日の午前中に、社内アカウントの ID と初期パスワードを受け取ります。初期パスワードは、受け取った当日に変更してください。

## 2. 貸与端末の初期設定

貸与端末には、ディスク暗号化と画面ロックを設定します。画面ロックの待ち時間は 5 分以内にしてください。

## 3. 社外からの接続

社外から社内システムへ接続する場合は VPN が必要です。設定手順は別の文書にまとめてあります。

## 4. 受講が必要な研修

- 情報セキュリティ研修（入社月のうちに受講）
- 障害対応の基礎研修（入社 3 か月以内に受講）

## 困ったときの連絡先

解決しない問題は、情報システム部のヘルプデスクへ連絡してください。
