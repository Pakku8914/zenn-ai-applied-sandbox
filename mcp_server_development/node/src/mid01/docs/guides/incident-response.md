# 障害対応の初動手順

## 1. 影響範囲の確認

障害の発生に気づいたら、まず影響範囲を確認します。影響範囲は「利用できない機能」と「影響する拠点」の 2 点で整理します。

## 2. 一次連絡

一次連絡は、障害対応チャンネルへ投稿します。障害レベル 2 以上は、15 分以内に上長へ一次連絡します。顧客への連絡が必要かどうかは広報が判断します。

## 3. 復旧作業と記録

復旧作業の記録は、開始時刻と実施内容を必ず残します。原因の調査は復旧のあとに行います。

## 障害レベルの目安

- レベル 1: 一部の利用者に影響
- レベル 2: 全社に影響
- レベル 3: 顧客に影響
